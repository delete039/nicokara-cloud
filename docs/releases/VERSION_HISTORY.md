# 版本历史映射

本表将早期的 `v0.x` 与 `v0.3.0-alpha.*` 命名统一为项目当前采用的产品版本。旧 Git 标签和旧部署包文件名保留用于追溯，不直接改写历史提交。

| 规范版本 | 对应功能阶段 | 旧版本或锚点 |
| --- | --- | --- |
| `v1.0` | 初始版本、基础上传、歌词处理和本地开发流程 | `v0.1.0` |
| `v1.1` | 分片上传、断点恢复、上传队列和多人调度 | `v0.1.1` |
| `v1.2` | 管理员监控、任务队列稳定性、worker 热更新、公告配置 | `v0.2.0` |
| `v2.0` | 浏览器优先的音频处理和基础 Kirakara 流程 | `v0.3.0-alpha.1` |
| `v2.1` | Kirakara 工程、LRC、双行布局、本地浏览器视频生成 | `v0.3.0-alpha.2` |
| `v3.0` | MMS 对齐架构、FA-Kara 高精度对齐、UVR 伴奏处理 | `v0.3.0-alpha.3`、`8249c8a`、`d0d2574` |
| `v3.1` | 结构化日志、管理员日志、音频续传、时间轴草稿保存 | 2026-08 中旬至 2026-08-20 更新 |
| `v3.2` | 注音审核、DeepSeek 读音修正、云端渲染和导出流程 | 2026-08-20 至 2026-09-07 更新 |
| `v4.0` | Yohane 优先、时间轴一致性、特殊符号、云端/本地渲染修复 | 2026-09-21 至 2026-09-28 更新 |
| `v4.1` | 双注音、多视频格式、公告历史、最新部署和当前修复 | 当前代码线 |

## 后续规则

- 当前版本为 `v4.1`。
- 下一组兼容性更新使用 `v4.2`，再下一组使用 `v4.3`。
- 只有出现需要迁移的 KRL、LRC、时间轴 JSON、API 或任务状态变化时，才进入 `v5.0`。
- 旧的 `v0.3.0-alpha.*` 标签不删除；新标签和发布说明使用本表中的规范版本。
